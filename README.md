# Python_Topics

A collection of exercises and scripts written while learning Python from
the ground up — covering syntax, data structures, control flow, and
object-oriented programming.

## Why this repo exists
This isn't polished production code — it's a record of learning. Each
file represents a concept I worked through: functions, loops, classes,
file I/O, and basic problem-solving. I'm keeping it public and
unedited as a baseline to measure progress against later.

## What's covered
- Core syntax and data types
- Control flow (loops, conditionals)
- Functions and scope
- Object-oriented programming basics
- Small standalone problem-solving scripts

## Note
If you're new to Python, feel free to browse — but this is a personal
learning log, not a tutorial. For structured references I used, see
the official [Python docs](https://docs.python.org/3/tutorial/).
